## Выполненные задания

### 1. Двоичный поток

В файле `src/binary-stream.js` реализованы классы:

```javascript
BinaryWriter
BinaryReader
```

Они построены на `DataView` и повторяют формат `QDataStream`:

| Тип | Представление |
|---|---|
| `int` | 4 байта, big-endian |
| `double` | 8 байт, big-endian |
| строка | длина в байтах (4 байта) и символы UTF-16 |
| нулевая строка | `ff ff ff ff` |

Благодаря записанной длине строки разделители между значениями не нужны.

### 2. Запись и чтение записи

Реализованы функции:

```javascript
encodeRecord()
decodeRecord()
```

Порядок записи совпадает с примером из методички `ds << str << v1 << d1`, порядок чтения — `ds >> str >> v1 >> d1`. Для записи `"Hello World!"`, `25`, `17.2` получается 40 байт:

```text
00000000  00 00 00 18 00 48 00 65 00 6c 00 6c 00 6f 00 20
00000010  00 57 00 6f 00 72 00 6c 00 64 00 21 00 00 00 19
00000020  40 31 33 33 33 33 33 33
```

* `00 00 00 18` — длина строки 24 байта (12 символов по 2 байта);
* `00 48 00 65 …` — символы `Hello World!`;
* `00 00 00 19` — число 25;
* `40 31 33 33 33 33 33 33` — число 17.2.

### 3. Обработка ошибок

* чтение за концом данных (обрезанный или повреждённый файл) вызывает ошибку, которая возвращается как `{ ok: false, error }`;
* целое число вне диапазона int32 не записывается;
* метод `atEnd()` показывает, прочитаны ли все данные.

### 4. Двоичные файлы

В файле `src/binary-file.js` реализованы функции на модуле `node:fs`:

```javascript
writeBinaryFile()
readBinaryFile()
writeRecordFile()
readRecordFile()
```

Скрипт `demo.js` записывает `output/data.bin`, выводит его содержимое в шестнадцатеричном виде и читает обратно.

### 5. Интерфейс

Страница `index.html` позволяет ввести строку, целое и вещественное число, сохранить их в файл `data.bin` и открыть файл `.bin`. Содержимое файла показывается в шестнадцатеричном виде.

## Запуск

Необходимо установить Node.js.

Из папки `practice-08` выполнить:

```powershell
node checks.js
node demo.js
```

Также доступен скрипт проверки:

```powershell
npm.cmd run check
```

Для проверки интерфейса из корня репозитория запустить `python -m http.server 5508` и открыть `http://127.0.0.1:5508/practice-08/index.html`.
