## Цель работы

Изучить методы обработки строк в JavaScript: сравнение, объединение, замену, изменение регистра, разбиение и объединение списков, проверку начала и конца строки, форматирование по шаблону, а также вывод диалоговых сообщений пользователю.

## Выполненные задания

### 1. Сравнение строк

В файле `src/string-tools.js` реализованы функции:

```javascript
compareStrings()
equalsIgnoreCase()
```

Сравнение выполняется с учётом регистра: `"Qt"` и `"QT"` различаются. Дополнительно реализовано сравнение без учёта регистра.

### 2. Пустая и нулевая строка

Реализованы функции:

```javascript
isEmptyString()
isNullString()
```

Как и в `QString`, различаются пустая строка `""` и отсутствующее значение `null`.

### 3. Объединение и замена

Реализованы функции:

```javascript
concatStrings()
replaceText()
```

`concatStrings("Библиотека", "Qt")` даёт `"БиблиотекаQt"`, поэтому добавлен необязательный разделитель. `replaceText("Программирование", "ирование", "а")` даёт `"Программа"`.

### 4. Регистр символов

Реализована функция:

```javascript
changeCase()
```

Перевод в нижний и верхний регистр корректно работает с кириллицей.

### 5. Разбиение и объединение

Реализованы функции:

```javascript
splitWords()
joinWords()
```

`splitWords("Библиотека Qt ")` возвращает три элемента, последний из которых пустой. С флагом `skipEmptyParts` (аналог `Qt::SkipEmptyParts`) пустые части отбрасываются.

### 6. Начало и конец строки

Реализована функция:

```javascript
checkEdges()
```

Она использует `startsWith()` и `endsWith()`.

### 7. Форматирование по шаблону

Реализованы функции:

```javascript
arg()
formatArgs()
```

Аналог `QString::arg()`: при каждом вызове заменяются все вхождения маркера `%N` с наименьшим номером. Пример из методички:

```text
"Дата: %1.%2.%3. %1 %4 шёл дождь." → "Дата: 17.09.2024. 17 сентября шёл дождь."
```

### 8. Диалоговые сообщения

В файле `src/message-box.js` реализована функция:

```javascript
showMessage(type, text, buttons)
```

Аналог `QMessageBox` на элементе `<dialog>`: информационное сообщение, предупреждение и сообщение об ошибке. Можно передать набор кнопок «Да», «Нет», «Отмена» и узнать, какая из них нажата.

## Запуск

Необходимо установить Node.js.

Из папки `practice-05` выполнить:

```powershell
node checks.js
```

Также доступен скрипт проверки:

```powershell
npm.cmd run check
```

Для проверки интерфейса из корня репозитория запустить `python -m http.server 5505` и открыть `http://127.0.0.1:5505/practice-05/index.html`.
