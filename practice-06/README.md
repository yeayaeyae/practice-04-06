## Выполненные задания

### 1. Поиск IP-адреса

В файле `src/regex-tools.js` реализованы функции:

```javascript
containsIp()
findIp()
```

Используется шаблон из методички:

```javascript
/[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}/
```

Точка экранирована. Без экранирования она означает «любой символ», и строка `1z2y3x4` ошибочно распознаётся как адрес. Это показано в проверках.

Дополнительно реализована функция `isValidIp()` — строгая проверка всей строки, где каждая часть адреса лежит в диапазоне 0–255.

### 2. Ветвление

Реализована функция:

```javascript
hasDomain()
```

Шаблон `(\.com|\.ru)$` совпадает, если совпадает одна из ветвей: `www.bhv.ru` — да, `www.bhv.de` — нет.

### 3. Сопоставление и извлечение подстроки

Реализована функция:

```javascript
matchPattern(pattern, text)
```

Аналог `QRegularExpressionMatch`: возвращает `hasMatch` и метод `captured()`. Шаблон `\d\d \w+` в строке `abc123 def` даёт `captured(0) == "23 def"`.

### 4. Нумерованные и именованные группы

Реализована функция:

```javascript
parseDate()
```

Дата `08/12/1985` разбирается шаблоном с именованными группами:

```javascript
/^(?<date>\d\d)\/(?<month>\d\d)\/(?<year>\d\d\d\d)$/
```

Группы доступны и по номеру (`captured(1)`), и по имени (`captured("month")`). Дополнительно проверяется, что дата существует (`31/02/2024` отклоняется).

### 5. Тестер шаблонов

Реализована функция:

```javascript
findAll(source, flags, text)
```

Она находит все совпадения с позициями и группами. Ошибка в шаблоне (например, `(abc`) обрабатывается и не ломает страницу.

### 6. Интерфейс

Страница `index.html` содержит тестер шаблонов с готовыми примерами из методички и таблицей совпадений, а также форму проверки значения на IP-адрес, домен и дату.

## Запуск

Необходимо установить Node.js.

Из папки `practice-06` выполнить:

```powershell
node checks.js
```

Также доступен скрипт проверки:

```powershell
npm.cmd run check
```

Для проверки интерфейса из корня репозитория запустить `python -m http.server 5506` и открыть `http://127.0.0.1:5506/practice-06/index.html`.
