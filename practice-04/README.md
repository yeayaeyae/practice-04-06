## Цель работы

Изучить работу с вещественными числами в JavaScript: преобразование строки в число и обратно, форматы вывода, обработку бесконечности и значения NaN, а также тригонометрические функции с выбором единиц измерения угла.

## Выполненные задания

### 1. Преобразование строки в число

В файле `src/real-numbers.js` реализована функция:

```javascript
parseReal()
```

Функция принимает строку, удаляет внешние пробелы, допускает запятую или точку как разделитель и проверяет формат регулярным выражением. Некорректный ввод (`""`, `12a`, `abc`) не превращается в ноль, а возвращает ошибку.

### 2. Арифметические операции

Реализована функция:

```javascript
calculate()
```

Она выполняет сложение, вычитание, умножение и деление двух введённых чисел и проверяет результат.

### 3. Бесконечность и не число

Реализована функция:

```javascript
checkResult()
```

Аналог проверок `qIsInf()` и `qIsNaN()`:

* `Number.isFinite()` — проверка на бесконечность (переполнение `1.7e308 + 1.7e308`, деление на ноль);
* `Number.isNaN()` — проверка на «не число» (`Infinity * 0`, `0 / 0`).

### 4. Форматы вывода

Реализована функция:

```javascript
formatNumber(value, format, precision)
```

Аналог `QString::number(value, format, precision)` с пятью форматами:

| Формат | Описание | Пример |
|---|---|---|
| `g` | автоматический выбор, 6 значащих цифр по умолчанию | `0.3` |
| `G` | то же в верхнем регистре | `1E-05` |
| `e` | экспоненциальный вид | `1.235e+04` |
| `E` | экспоненциальный вид в верхнем регистре | `1.235E+04` |
| `f` | точное число знаков после запятой | `0.3000000000` |

### 5. Тригонометрические функции

Реализованы функции:

```javascript
sine()
cosine()
arcsine()
toRadians()
toDegrees()
roundTo()
```

Угол переводится из градусов в радианы по формуле `grad * Math.PI / 180`. Так как значения тригонометрических функций приближённые (`Math.sin(Math.PI)` даёт `1.22e-16`), результат округляется. Для арксинуса проверяется диапазон аргумента `[-1; 1]`.

### 6. Интерфейс

Страница `index.html` содержит калькулятор с выбором операции, формата и точности, а также блок тригонометрии с переключателями `radioButton_grad` и `radioButton_rad`. Выбранный переключатель проверяется свойством `checked` (аналог `isChecked()`).

## Запуск

Необходимо установить Node.js.

Из папки `practice-04` выполнить:

```powershell
node checks.js
```

Также доступен скрипт проверки:

```powershell
npm.cmd run check
```

Для проверки интерфейса из корня репозитория запустить `python -m http.server 5504` и открыть `http://127.0.0.1:5504/practice-04/index.html`.
