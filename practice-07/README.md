## Выполненные задания

### 1. Текстовый поток

В файле `src/text-stream.js` реализованы функции, которые работают и в браузере, и в Node.js:

```javascript
splitLines()
writeValues()
readTokens()
readRecord()
textStats()
```

* `splitLines()` — построчное чтение, аналог `readLine()` до `atEnd()`;
* `writeValues()` — запись значений через пробел, аналог `ts << "Hello" << " " << 12`;
* `readTokens()` — чтение значений, разделённых пробельными символами, аналог `ts >> value`;
* `readRecord()` — чтение записи `h w v1 d1` с проверкой типов: из `Hello world! 12 63.5` получаются `"Hello"`, `"world!"`, `12` и `63.5`.

### 2. Работа с файлами

В файле `src/text-file.js` реализованы функции на модуле `node:fs`:

```javascript
writeTextFile()
appendTextFile()
readTextFile()
readLines()
writeRecordFile()
readRecordFile()
```

Режимы открытия соответствуют методичке:

* `writeTextFile()` — `WriteOnly`, прежнее содержимое удаляется;
* `appendTextFile()` — `Append`, данные добавляются в конец;
* `readTextFile()` — `ReadOnly`.

Файлы читаются и записываются в UTF-8. Ошибки открытия (отсутствующий файл, несуществующий каталог) не прерывают программу, а возвращаются как результат `{ ok: false, error }`.

### 3. Выбор файла пользователем

Страница `index.html` — аналог `QFileDialog`:

* «Открыть файл…» — выбор файла через `<input type="file">`. Если пользователь закрыл окно или нажал «Отмена», текст не меняется;
* «Сохранить» — сохранение текста в файл с указанным именем. Пустое имя означает отмену;
* перед открытием другого файла при несохранённых изменениях запрашивается подтверждение, а изменённый документ отмечается звёздочкой в заголовке.

### 4. Демонстрация

Скрипт `demo.js` записывает файл `output/file.txt`, дописывает в него строки, читает построчно, затем записывает и читает `output/stream.txt` через поток.

## Запуск

Необходимо установить Node.js.

Из папки `practice-07` выполнить:

```powershell
node checks.js
node demo.js
```

Также доступен скрипт проверки:

```powershell
npm.cmd run check
```

Для проверки интерфейса из корня репозитория запустить `python -m http.server 5507` и открыть `http://127.0.0.1:5507/practice-07/index.html`.

## Результаты проверки

В проекте предусмотрен автоматизированный файл `checks.js`. Файлы создаются во временном каталоге, который удаляется после проверки.

Проверяются:

1. построчное разбиение, в том числе с `\r\n` и пустыми строками;
2. запись значений через пробел;
3. чтение значений, разделённых пробелами;
4. чтение записи `h, w, v1, d1`;
5. ошибки разбора записи;
6. статистика текста;
7. запись и чтение файла с кириллицей;
8. перезапись файла в режиме `WriteOnly`;
9. добавление в режиме `Append`;
10. запись и чтение через поток;
11. чтение пустого файла;
12. ошибка открытия отсутствующего файла;
13. ошибка записи в несуществующий каталог.
